Entrants write the one line an AI agent prints the moment it breaks production: a brutally honest error message or postmortem excuse, under 200 characters, free to enter, judged in pairs by the house judge. This entry's program writes that one line, deterministically, to `entry.txt` in the output directory.

## Run it
